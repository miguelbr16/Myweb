# docs/playbooks/

## Propósito

**Playbooks operativos** — guías paso a paso para tareas repetibles: intake, onboarding proyecto, QA pre-deploy, deployment, handoff cliente, outbound ventas.

Orientados a ejecución por una persona o IA con criterio de éxito claro.

## Qué debe vivir aquí

- SOPs (Standard Operating Procedures)
- Checklists (QA landing, SEO on-page, deployment, handoff)
- Scripts de conversación / ventas (borradores)
- Instrucciones para Skills de Cursor (referencia; implementación en `.cursor/` cuando exista)

## Qué NO debe vivir aquí

- Contexto general del proyecto → `docs/context/`
- Decisiones arquitectónicas → `decisions/` o `adr/`
- Aprendizajes retrospectivos → `docs/learnings/`
- Specs de cliente
- Automatizaciones n8n export (cuando existan, carpeta dedicada futura o `spikes/`)
