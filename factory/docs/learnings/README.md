# docs/learnings/

## Propósito

**Aprendizajes acumulados** tras entregas, conversaciones comerciales, spikes y retrospectivas (“harvest”).

Alimenta el loop: ENTREGA → RETROSPECTIVA → MEJOR TEMPLATE/COMPONENTE/PROCESO.

## Qué debe vivir aquí

- Retrospectivas post-proyecto (`YYYY-MM-<cliente-o-codename>.md`)
- Qué reutilizar vs qué fue custom innecesario
- Resultados de experimentos comerciales (pricing, ICP) — con etiquetas FACT/HYPOTHESIS
- Notas de conversaciones con clientes (sin PII innecesaria)

## Qué NO debe vivir aquí

- Decisiones formales → `decisions/`
- Contratos y specs → `docs/factory/`, `specs/`
- Estrategia forward-looking no validada → `docs/strategy/`
- Datos personales de leads o pacientes
- Secrets o credenciales de clientes
