# docs/strategy/

## Propósito

Documentos de **estrategia de negocio**: ICP, posicionamiento, oferta, pricing, go-to-market, priorización de verticales.

## Qué debe vivir aquí

- Definición de ICP y verticales objetivo
- Propuesta de valor y diferenciación
- Estructura de oferta productizada (entregables, duración, pricing **como hipótesis**)
- Planes comerciales y criterios de validación
- Decisiones de qué vender / qué no vender (con etiquetas FACT/HYPOTHESIS/DECISION)

## Qué NO debe vivir aquí

- Arquitectura técnica → `docs/architecture/`
- Contratos SiteSpec → `docs/factory/` y `specs/`
- ADRs → `docs/architecture/adr/`
- Retrospectivas de proyectos → `docs/learnings/`
- Pipeline de ventas en vivo (estado) → herramienta de PROJECT STATE (Notion, etc.)
